Multi-terminal Sync

Keep all your POS terminals in perfect sync with the latest product information.

This module enhances Odoo's Point of Sale by automatically synchronizing product changes (like price changes, and product information) across POS sessions in real-time, eliminating the need for manual refreshes.

The module uses Odoo's bus system to push updates to all connected POS sessions whenever product data changes in the backend. This ensures that all terminals have the most current information without requiring manual refresh.

Yes, the module includes a toggle switch in the POS settings that allows you to enable or disable the real-time synchronization feature as needed.
